Every experiment folder contains `source_code.py` and a `screenshots/` directory. Prolog experiments also contain their actual `.pl` implementation; their Python file is a launcher, not a Python reimplementation of Prolog.

## Run

Open the desired experiment folder in a terminal and run:

```powershell
python source_code.py
```

The 20 Prolog questions require SWI-Prolog installed and `swipl` available on `PATH`. The Python launchers report a clear message if it is missing. Each `.pl` file includes sample query comments where appropriate. Example datasets, graph structures, thresholds, or puzzle boards are defined near the top of the relevant source file and can be edited.

Experiment 1 uses a sample graph because the graph referenced by the question was not supplied in the PDF text. Replace `GRAPH` in its source with the intended state-space graph if available. The admission and eligibility cutoff values, as well as other unspecified example data, are documented in their source files as illustrative.
